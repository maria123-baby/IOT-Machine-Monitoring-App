# IOT Machine Monitoring Dashboard

A React-Redux application to monitor machines using IoT Sensor Data

## Features
- Dashboard containing the information of machines
- Feature to acknowledge fault machines
- Search bar for searching machines based on names
- Filtering using status

## Tech Stack

### Frontend
- React
- Redux
- Bootstrap

### Backend
- Node.js
- Express.js

## Instructions to run the code

### Backend
- cd Server
- node server.js

### Frontend
Open another Terminal
- cd Client
- npm run dev
